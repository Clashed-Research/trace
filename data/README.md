# Sample data provenance

Every record in this directory is **fictional synthetic test data created for the Open Agent Hackathon 2026**.

- No record describes a real person, customer, company, payment, support interaction, or advertising account.
- Identifiers such as `C-001` and `L-101` are generated fixture identifiers.
- All campaign names, spend, revenue, refund, ticket, and performance values are invented for demonstrating reconciliation, critique, provenance, and fallback behavior.
- The files are intentionally small so judges can reproduce the demo without credentials or network access.
- Do not replace these fixtures with private or production data in a public repository.

Live data should be accessed through Zetaris using local environment variables and must never be committed.
