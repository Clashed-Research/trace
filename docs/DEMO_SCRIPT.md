# Three-minute demo script

## 0:00–0:25 — Problem

“Ad platforms tell you which campaign created leads. They cannot tell you which customers stayed, refunded, or overloaded support. Trace follows every marketing dollar across four disconnected systems.”

Show the source readiness strip and select **Refund leak**.

## 0:25–1:15 — Run

Run the default question. Open **Investigation** and narrate the roles: planner, source mapper, identity resolver, analyst, critic, planner revision, Nemotron second opinion, and decision agent.

Emphasize that the critic catches the apparent lead winner losing retained revenue.

## 1:15–2:00 — Decision

Return to **Overview**. Show Spring Growth at 0.09× retained ROAS and the revised 35% decrease. Compare it with Founder Stories at 3.28×.

## 2:00–2:35 — Fragmented intelligence

Open **Sources**. Show the four systems and inconsistent labels such as `Spring Growth` and `spring-growth` resolving to one identity.

## 2:35–2:55 — Auditability

Open **Evidence**, filter to Spring Growth and Contradicts, then select a support record. Export the Markdown audit report.

## 2:55–3:00 — Close

“Trace does not generate marketing copy. It makes a real budget decision, challenges itself, and shows every receipt.”
